## 🚀 Getting Started Locally

### 1. Install Dependencies

```bash
npm install
```

### 2. Start Local Development Server

```bash
npm start
```

Runs the application on `http://localhost:3000/`.

### 3. Production Build

```bash
npm run build
```

Creates an optimized, production-ready static bundle in the `build/` directory.
